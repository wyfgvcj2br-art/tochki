# Установка ТОЧКИ 2.6.0

**Prod. by Saudade_meow**

Скачайте один файл `Tochki-2.6.0-Setup-x64.exe` из проверенных артефактов Windows CI
(после утверждения версии — из Releases). Запустите его и пройдите русскоязычный мастер.
По умолчанию программа устанавливается в `%ProgramFiles%\Tochki`; папку можно выбрать.
Установка требует разрешения администратора. Само приложение запускается с обычными
правами пользователя через меню «Пуск» → «Точки» либо необязательный ярлык рабочего стола.
На последнем экране можно сразу запустить программу. Python и интернет не нужны.

## Данные и результаты

| Назначение | Расположение установленной версии |
| --- | --- |
| EXE, библиотеки, ресурсы, Fixed WebView2 | выбранная папка установки |
| Настройки и справочник | Known Folder LocalAppData / Tochki / Data |
| Профиль WebView2 | Known Folder LocalAppData / Tochki / WebView |
| Журналы | Known Folder LocalAppData / Tochki / Logs |
| Отчёты по умолчанию | Known Folder Documents / Точки / Результаты |

Приложение получает LocalAppData, Documents и Fonts через Windows Known Folders API.
Перенаправление «Документов», кириллица и пробелы учитываются. Папка установки не
используется для изменяемых данных. В настройках по-прежнему можно выбрать другой
каталог результатов. Отключённый или недоступный диск вызывает сообщение, а не
молчаливую замену выбранной папки.

## Переход из Portable

При первом запуске установленной версии откроется окно импорта. Выберите старую
папку Portable, внутри которой находится `Data`, проверьте список и нажмите
«Импортировать». Можно нажать «Пропустить импорт» и вернуться через
«Импорт из Portable» в настройках папки отчётов.

Импортируются только `settings.json`, `collector-names.json` и
`collector-names.json.bak`. Это все актуальные пользовательские JSON-файлы,
выявленные при аудите версии 2.5.0. Настройки в localStorage дублируются в JSON
нативной версии; кеш WebView2 не является источником справочника и не переносится.
Журналы, `desktop-state.json`, `.server.json` и lock-файлы — служебные и не импортируются.

Файлы проходят проверку JSON, настроек, ID и ФИО. Повреждение основного файла или
резервной копии останавливает весь импорт до исправления. Если данные уже существуют,
программа отдельно просит подтвердить замену. Прежние файлы сохраняются в
`Data/Backups/portable-import-<дата>-<идентификатор>`. Изменение файлов после просмотра
списка требует повторной проверки. При сбое записи уже изменённые файлы откатываются.
Сами файлы старой Portable-версии не изменяются и не удаляются.

Отчёты остаются в прежней папке. Если в Portable был явно выбран относительный путь,
он преобразуется в абсолютный путь старой папки; для переноса результатов используйте
обычное копирование Windows и затем выберите новую папку в программе.
Если папка не была выбрана, используется новый каталог в «Документах».
Импортированные имена применяются к следующим загрузкам XLSX.

## Обновление, удаление и восстановление

Закройте программу и запустите новый установщик поверх существующей версии.
Постоянный AppId сохраняет папку и запись в списке установленных программ.
Установщик использует Windows Restart Manager для закрытия занятых файлов.
Пользовательские папки не входят в payload установщика и не перечислены в удалении.

Удаление: «Параметры Windows» → «Приложения» → «ТОЧКИ» → «Удалить».
Настройки, справочник, профиль, журналы и сформированные отчёты сохраняются.
Повторная установка использует существующие данные того же пользователя Windows.
Для ручного восстановления закройте программу, скопируйте нужные JSON из Data/Backups
в Data, предварительно сохранив текущие файлы.

## Сборка разработчиком

Windows 10/11 x64, Python 3.12.10 x64. На машине сборки нужен интернет либо заранее
загруженные зависимости, CAB и компилятор; установка готового EXE работает автономно.

```powershell
python -m pip install -r requirements-build.txt
python -m unittest discover -s tests -v
python scripts/build_installer.py --accept-runtime-license
# Дополнительная Portable-сборка:
python scripts/build_portable.py --accept-runtime-license
python scripts/smoke_portable.py dist/portable/Точки
```

Прочтите licenses/WEBVIEW2-LICENSE.txt перед передачей флага согласия.
Inno Setup 7.1.1 загружается из официального GitHub-релиза и проверяется по SHA-256.
WebView2 155.0.4283.60 и SHA-256 CAB сохранены от 2.5.0. Все Python-зависимости,
включая транзитивные, зафиксированы. Сценарий Inno: `installer/Tochki.iss`;
метаданные EXE и DPI manifest: `scripts/windows_metadata.py`, `installer/app.manifest`.

Основной результат: `dist/Tochki-2.6.0-Setup-x64.exe`, `dist/SHA256SUMS.txt`,
`dist/installer-build.json`. Inno сначала создаёт единый `Tochki-Setup-x64.exe`,
после чего build-скрипт добавляет версию к имени. Payload: `dist/installed/Точки`.
Portable ZIP: `dist/portable`. Установщик не требует распаковки пользователем.

Воспроизводимы входные версии и процедура сборки. Побайтовая идентичность EXE между
разными машинами не гарантируется: компиляторы и PE-ресурсы могут содержать время.
SHA-256 относится к конкретному загруженному артефакту; provenance записан в JSON.

`scripts/smoke_installer.ps1` выполняется только на одноразовой тестовой Windows:
он устанавливает программу, создаёт обычного пользователя, проверяет обновление,
удаление и повторную установку. Не запускайте этот сценарий на рабочем компьютере.
Workflow не создаёт релиз и не сливает ветку автоматически.
