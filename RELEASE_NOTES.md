# Точки 2.3.0 Portable

- Окно неизвестных сборщиков: ID, ТТ и даты; имена из других строк — только подсказки.
- Ручные привязки ID → ФИО сохраняются рядом с программой и применяются к следующим выгрузкам, включая PNG и Excel.
- Отдельный справочник для исправления ФИО, резервная копия и защита от одновременной перезаписи.
- Исходные XLSX, числовые показатели и заполненные имена из выгрузки не меняются при привязке.
- ID 0 временно скрыт из детализации и её итогов. Исключённые суммы отражены в проверке; разбор ID 0 добавлен в дорожную карту.

Распакуйте всю папку. Запустите «Точки.exe». При обновлении закройте приложение и сохраните свои `Data` и `Результаты`. Личные справочники и рабочие выгрузки не включены в публичный архив.
