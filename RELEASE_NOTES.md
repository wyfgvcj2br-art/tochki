Новая отдельная функция: детализация сборщиков по дням с просроком ТТ от 6% включительно.

- Кнопка «Детализация сборщиков» в меню; нужны выгрузки по магазинам и по сборщикам.
- Один PNG на каждую ТТ с превышениями, до 7 календарных дней.
- Порог проверяется по общему просроку ТТ от 6% включительно, до округления.
- Для каждого выбранного дня показаны ФИО, успешные заказы, просроченные заказы и общий процент сборщика.
- Суммы сборщиков сверяются с ТТ; пропуски и расхождения блокируют сборку.
- Строки без ФИО сохранены. Части одного сборщика с одним номером объединяются, включая варианты названия ТТ.
- Режимы обычных отчётов и их данные сохранены.

Portable включает собственный WebView2. Распакуйте всю папку и запустите Точки.exe.
