Детализация использует только показатели из таблицы сборщиков.

- Таблица магазинов определяет дни отбора: общий просрок ТТ от 6% включительно.
- Дневные итоги, ФИО, заказы, просрок и проценты детализации берутся из выгрузки сборщиков.
- Расхождение с итогами ТТ показывает предупреждение и выделение даты; сборка продолжается без подгонки чисел.
- Основная выгрузка группируется по началу слота, выгрузка сборщиков — по дате сборки; названия полей сохранены в проверке.
- По агрегированным выгрузкам нельзя установить уникальные заказы и сборочные листы; произвольная дедупликация не выполняется.
- Один PNG на ТТ, до 7 дней в изображении.
- Исходные файлы не изменяются.
