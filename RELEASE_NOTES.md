# ТОЧКИ 2.6.0 — установочная Windows-версия

**Prod. by Saudade_meow**

- Один автономный Inno Setup EXE: установка в Program Files или выбранную папку,
  русскоязычный мастер, меню «Пуск», необязательный ярлык рабочего стола и штатное удаление.
- Настройки и справочник перенесены в LocalAppData/Tochki/Data, профиль WebView2 —
  в WebView, диагностика — в Logs. Отчёты по умолчанию — «Документы/Точки/Результаты».
- Первый запуск предлагает безопасно импортировать JSON из Portable. Проверка формата,
  подтверждение замены, резервные копии, защита от изменения файлов после проверки и откат
  частичного импорта; исходная Portable-папка сохраняется.
- Существующий интерфейс, расчёты, зелёные PNG, Excel, справочник и выбор папки сохранены.
- Fixed Version WebView2 и Python включены. Приложение работает без повышения прав,
  консоли, BAT/CMD и подключения к интернету.
- Добавлены сведения о продукте, постоянный AppUserModelID, DPI manifest и нормальное
  завершение локального HTTP-сервера после закрытия окна.
- Portable остаётся дополнительным форматом. CI собирает оба формата, тестирует их
  и сохраняет EXE, контрольные суммы и доказательства проверок в Artifacts.

Подробности: INSTALLATION.md. Фактически выполненные и непроведённые проверки:
VALIDATION_REPORT.md. Ветка подготовки 2.6.0 не публикует финальный релиз автоматически.
