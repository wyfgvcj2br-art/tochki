# Дорожная карта

- [ ] Разобрать служебный ID 0: определить, как отличать людей за этим ID, и согласовать способ привязки к ФИО. Пока ID 0 скрыт из окна привязки и детализации (строк и итогов PNG/Excel). Число исключённых строк, заказов и просрочек остаётся в «Проверка.json»; дни превышения выбираются по исходному просроку ТТ.

## Готово в 2.3.0

- Окно неизвестных сборщиков: ID, торговые точки, даты и подсказки из других строк.
- Ручная подтверждённая привязка ID → ФИО и редактирование справочника.
- Локальное сохранение, автоматическое применение в следующих выгрузках, резервная копия и защита от одновременной перезаписи.
