# Монограмма ВВ

Товарный знак и фирменная монограмма принадлежат ВкусВиллу.

Палитра и описание монограммы: https://vkusvill.ru/brand/
Контуры букв: https://github.com/Delta-Icons/android/blob/24f1a3d98021ac5a3e3bd91c5e5d77802582c7c2/resources/vectors/vkusvill.svg
Из исходной иконки взяты только контуры ВВ; фон и трансформация иконки исключены.
Цвет заменён на фирменный #2DBE64.

vv-monogram.png — прозрачная растровая версия vv-monogram.svg (368 × 208),
подготовленная для Pillow. SVG и PNG включаются в существующую папку ui portable-сборки.
Сеть и SVG-библиотеки во время работы приложения не используются.
